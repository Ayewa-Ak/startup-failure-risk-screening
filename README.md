# Early-Stage Startup Failure Prediction: A Machine Learning Risk-Screening Framework for Investors

Master in Data Science and Business Analytics, Bologna Business School, University of Bologna.
Supervisor: Prof. Claudio Sartori. Reference course: Entrepreneurial Finance (Prof. Alexander Groh).

## Business problem
Investors need to prioritise which young firms deserve closer due diligence. This project
ranks young Italian limited companies by estimated failure risk, as a screening aid and not
as a verdict on which firms are "safe".

## Data
Source: AIDA (Bureau van Dijk, Moody's), accessed through the University of Bologna library.
Sample: SRL-type companies incorporated 2016-2018 that filed 2019 accounts (211,098 firms).
Raw data is not included for licensing reasons. See docs/search_strategy.md to regenerate it.

## Project structure
src/startup_risk/ (code), notebooks/ (exploration), data/ (raw and processed, not committed),
configs/ (settings), tests/ (unit tests), docs/ (data dictionary, label definition, search strategy),
reports/figures/ (figures), models/ (trained models, not committed).
